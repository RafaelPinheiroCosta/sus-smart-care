# Azure/Bicep

Infraestrutura de referência do MVP em AKS + ACR + Log Analytics. PostgreSQL, Redis, Kafka/Event Hubs, Key Vault e observabilidade gerenciada são evoluções separadas para evitar criar custos desnecessários durante o desenvolvimento. Antes de executar, faça `az deployment group what-if` e revise SKUs/região/créditos.
