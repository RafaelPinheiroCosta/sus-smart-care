# Cenários obrigatórios de demonstração do MVP

## A — Paciente digital
Consulta estimativa -> pré-atendimento -> pré-anamnese -> chegada/check-in -> triagem -> fila -> consulta de posição/tempo.

## B — Paciente sem smartphone
Registro por recepção/totem -> triagem -> fila -> dashboard anonimizado -> saída registrada -> retorno dentro/fora da tolerância -> atualização operacional da posição.

## C — Dependente/representado
Responsável autenticado seleciona paciente representado -> pré-atendimento -> histórico continua no mesmo Patient -> no futuro o próprio paciente pode criar conta própria sem migração de histórico.

## D — Ambulância
Identidade conhecida ou provisória -> PreHospitalEncounter -> devices/gateway autenticados -> TelemetrySession -> observações -> risco/alerta pré-chegada -> ETA -> hospital prepara recepção -> chegada integra-se à mesma Visit/Patient.
